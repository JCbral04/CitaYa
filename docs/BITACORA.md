# Bitacora

**Prototipo inicial (Entrega 1 — S14)(3/11/2026):** interfaz web adaptable a computadores y móviles que incluye:

- Panel del día con indicadores visuales: citas activas, confirmadas, pendientes e ingresos estimados.
- Gráfica interactiva de citas registradas con cambio de periodo (semana / mes) usando Chart.js.
- Listado de las próximas citas con su estado (confirmada, pendiente, reprogramada, cancelada).
- Catálogo de servicios del negocio con duración y precio.
- Navegación responsive con menú móvil.

> Los datos son simulados en JavaScript a manera de mockdata. Aún no hay backend, base de datos ni autenticación.
